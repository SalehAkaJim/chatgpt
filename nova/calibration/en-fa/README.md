# English calibration set

Twelve authored text samples (two each at A1, A2, B1, B2, C1 and C2), plus the thirteen revised canonical A1 Lessons, form a 25-text calibration corpus. Each added sample includes a scenario, changing played/interlocutor roles, dialogue, useful chunks, a comprehension question with option explanations, and a hidden-example production task. C2 adds multiple written sources; open responses include criteria and illustrative answers.

These files are draft teaching samples, not a completed six-level course. They are intentionally outside `nova/courses/*/lessons/`: no SQL, audio generation or automatic learner progression uses them. Prerequisite knowledge is explicit and may not yet have Lessons in the active course. A teacher/model must review open responses by meaning and the rubric; model text must never become the sole accepted answer.

Level alignment is provisional. Real learner trials and perceptual audio QA have not happened. The text-only samples expose differences in task demand before spending on audio or developing advanced response evaluation. The main 13 remain the only runtime Lessons.
