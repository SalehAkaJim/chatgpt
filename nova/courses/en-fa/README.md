# English → Persian

Course/Level definitions: [course.source.json](course.source.json).

The canonical Lesson set is generated and validated from `lessons/*/lesson.source.json`; the current active A1 prefix is **0001–0148**. Do not maintain a hand-written Lesson list here as the source of truth. Use the generated [Course catalog](../index.json), `nova/curriculum/en-fa/language_curriculum_summary.json`, and `factory_validation.json` for the live prefix and validation state.

Story continuity uses interleaved arcs, variable played roles, a minimum return distance, and cross-character arcs. Adjacent Lessons must not reuse the same cast or learner role. New characters require a verified independent audio voice before they can enter canonical content.

Each Lesson has independent canonical, quality, Persian, semantic-review, audio and MySQL evidence. Quality v3 additionally prevents exact dialogue testing before exposure, repeated scoring of the same full target sentence, generic/meta story copy, and unnecessarily exact STT matching where a safe contraction/expansion equivalent exists.

Technical PASS does not equal public educational readiness. Real learner evidence remains a separate release gate.
