# Nova production curriculum workspace

This directory is the permanent source-driven curriculum workspace for `en-fa`.

- `factory.config.json` controls production gates and auto-discovers canonical Lessons.
- `curriculum_state.json` is regenerated from committed canonical Lessons.
- `language_curriculum_summary.json` is regenerated by the production curriculum pipeline.
- `factory_validation.json` records canonical/reference/quality/story/naturalness/generativity results.
- `specs/NNNN.json` is the pre-authoring contract for Lesson NNNN. A spec becomes immutable once the corresponding `lesson.source.json` exists.

Production authoring order:

1. Refresh committed language-reference snapshots when sources change.
2. Generate/refresh the next Lesson spec.
3. Author the Lesson against that spec.
4. Run Language Plan + Reference + Naturalness + Generativity + content-quality gates.
5. Compile/import only after all text gates pass.
6. Generate paid TTS only after text/reference/content approval.

Do not store experimental probes here. Historical source snapshots live under `nova/reference-snapshots/`.
