# Content System

## Non-negotiable content rule
Educational content is source-backed. The pipeline does not author words, translations, example sentences, dialogues, grammar explanations, or exercises.

Allowed operations are structural only: fetch, parse, normalize transport/encoding, attach provenance, deduplicate, link, classify when a source supplies the classification, and map source hierarchy into the application hierarchy.

If a source does not provide a field, the importer leaves it absent or null. It must not invent a replacement.

## Core model
The canonical model remains concept-centered and multilingual:

```text
Source
  -> Unit
    -> Lesson
      -> Concept / Lexeme / Word Form
      -> Utterance
      -> Dialogue
      -> Grammar Point
      -> Exercise
```

A source curriculum does not have to use the same hierarchy. Importers map source structure into this model while preserving source order and text.

## Provenance
Every imported batch identifies:
- source ID
- work title
- author/publisher when available
- source URL
- license and license URL
- retrieval date

Source-specific IDs and ordering are preserved so imported data can be reproduced and audited.

## CEFR
CEFR is not inferred merely to satisfy the database. If a source explicitly supplies CEFR, it can be imported. If it does not, `cefr` remains null until a separate evidence-backed mapping is approved.

## Learner language
The database is not English-based. A source may contain English translations because English was the source's instructional language. Those translations are imported as source data; they do not define the learner language of the product. Persian localization can be added later from an approved translation source/process without changing the German source content.

## German reference import
The first source-backed implementation uses COERLL's **Deutsch im Blick**. The source describes itself as a first-year German curriculum and is published under CC BY 4.0.

Current import scope is intentionally narrow:
- include publisher-authored vocabulary pages for chapters 1-10
- chapter -> unit
- vocabulary semantic section -> lesson
- German/English vocabulary pair -> concept item
- exclude audio
- exclude songs and third-party media
- exclude externally linked copyrighted material

The importer is `scripts/import_coerll_deutsch_im_blick.py` and the source manifest is `sources/de/coerll-deutsch-im-blick/source.json`.

## Audio
Audio generation is paused. No source audio is imported. No ElevenLabs audio is generated by the current pipeline. Audio will be added only when explicitly enabled later.

## Validation policy
An importer must fail instead of filling gaps. Parser failures, missing sections, malformed source rows, or schema failures are hard errors. This prevents a source change from silently turning into generated or guessed educational content.
